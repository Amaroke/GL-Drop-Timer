# GL Drop Timer

Suivi des temps de recharge des objets gratuits de l'inventaire Galaxy Life : Starbatterie (11h), Boîte à outils (23h), Casque (35h).

Site : <https://amaroke.github.io/GL-Drop-Timer/>

## Stack

React, TypeScript, Tailwind CSS, Vite. Déploiement automatique sur GitHub Pages via GitHub Actions à chaque push sur `main`.

## Développement

```sh
npm install
npm run dev
```

```sh
npm run build
```
