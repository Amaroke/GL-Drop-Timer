# Firebase Resources

## Knowledge

- [Add Firebase to your JavaScript project](https://firebase.google.com/docs/web/setup)
  Official docs on `initializeApp` and the config object (`apiKey`, `authDomain`, `projectId`, `appId`). Use for: `src/config/firebaseConfig.ts`.
- [Authenticate Using Google with JavaScript](https://firebase.google.com/docs/auth/web/google-signin)
  Official docs on `GoogleAuthProvider` and `signInWithPopup`. Use for: `src/auth/firebaseAuth.ts`.
- [Access data offline (Firestore)](https://firebase.google.com/docs/firestore/manage-data/enable-offline)
  Official docs on `persistentLocalCache` and `persistentMultipleTabManager`. Use for: `createAppFirestore` in `src/store/firestoreDropStore.ts`.
- [Get started with Cloud Firestore Security Rules](https://firebase.google.com/docs/firestore/security/get-started)
  Official docs on the `match` / `allow` structure. Use for: `firestore.rules`.
- [Install, configure and integrate Local Emulator Suite](https://firebase.google.com/docs/emulator-suite/install_and_configure)
  Official docs on the `emulators` section of `firebase.json`. Use for: `firebase.json`.
- [Firebase CLI reference](https://firebase.google.com/docs/cli)
  Official docs on the role of `.firebaserc` and the `firebase.json` generated by `firebase init`. Use for: `.firebaserc`.
- [Fundamentals (Firebase docs)](https://firebase.google.com/docs/guides)
  What Firebase is as a platform, the product catalog. Use for: the "what is Firebase" framing.
- [Understand Firebase projects](https://firebase.google.com/docs/projects/learn-more)
  Project vs. app distinction, how registering a web app yields the config object. Use for: the console tour.
- [Manage Cloud Firestore with the Firebase Console](https://firebase.google.com/docs/firestore/using-console)
  Where the Data / Rules / Indexes / Usage tabs live in the console. Use for: the console tour.
