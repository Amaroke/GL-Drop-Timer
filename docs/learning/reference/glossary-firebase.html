Firebase Glossary

Vocabulary used in GL-Upgrade-Planner. See lesson 0001 — The Firebase files for full context.

Term Meaning in this project
FirebaseApp The instance created by initializeApp(config). One object, reused by Auth and Firestore. In code: getFirebaseApp in firebaseAuth.ts.
GoogleAuthProvider Describes the sign-in provider (Google only, here). Passed to signInWithPopup.
onAuthStateChanged Listener that fires a callback on every session change (sign-in, sign-out, restoring on load).
Firestore Firebase's document database. A document is a JSON object, organized into collections.
doc(db, "users", uid, "drops", dropId) Path to one specific document: collection users → document uid → subcollection drops → document dropId.
onSnapshot Real-time listener on a document or query: the callback fires on every change, local or remote.
persistentLocalCache Turns on local (IndexedDB) caching so reads/writes work offline. Without it, Firestore keeps nothing persisted between sessions.
persistentMultipleTabManager Lets several browser tabs share the same Firestore local cache.
Security rules (firestore.rules) Server-side code Firestore runs before every read/write to decide whether it's allowed. Replaces a traditional authorization backend.
request.auth In rules, the identity of the caller (null if signed out).
request.resource.data In rules, the data the client is trying to write, before it's accepted.
Firestore emulator A local copy of Firestore that runs on your machine (port 8080 here), for testing without touching real data.
.firebaserc File generated by the Firebase CLI that says which Firebase project to target by default (here, demo-gl-upgrade-planner).
FirebaseOptions TypeScript type of the config object passed to initializeApp: apiKey, authDomain, projectId, appId.
Spark / Blaze plan Spark = free, no card, no Cloud Functions. Blaze = pay-as-you-go, unlocks Cloud Functions. GL-Upgrade-Planner stays on Spark.
